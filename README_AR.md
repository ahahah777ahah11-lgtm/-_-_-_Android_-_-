# مدير الديون الذكي Android — النسخة التطويرية 3.0

هذه حزمة مشروع Android Studio ذات وظائف مالية محلية أساسية. **ليست APK مبنيًا أو موقّعًا**؛ بيئة إعداد الملفات هنا لا تحتوي على Android SDK/Gradle لتجميع APK والتحقق منه.

## وظائف هذه النسخة
- لوحة ملخص للديون المستحقة والمدفوعات وعدد العملاء.
- إضافة وتعديل العملاء محليًا باستخدام SQLite.
- البحث بالاسم أو رقم الهاتف.
- تسجيل الدفعات والحوالات يدويًا وربطها بالعميل.
- منع تكرار رقم الحوالة المرجعي عند إدخاله (إذا كان المرجع غير فارغ).
- سجل دفعات العميل ورصيده الحالي.
- فتح تطبيق SMS برسالة تذكير جاهزة.
- تصدير CSV.
- اختيار ملفات CSV والنصوص وExcel وPDF وSQLite لمعاينة البيانات والجداول محليًا.

## حدود الاستيراد الحالية
- CSV والنصوص: معاينة فقط؛ لا يوجد ترحيل تلقائي للصفوف.
- Excel: معاينة أول 30 صفًا لكل ورقة.
- PDF: استخراج النص من PDF النصي فقط؛ لا يوجد OCR للملفات المصورة.
- SQLite: اكتشاف أسماء الجداول فقط؛ لم تكتمل شاشة اختيار الجدول ومطابقة الأعمدة وترحيل الصفوف.
- لا توجد مزامنة جوالي/فلوسك لأن ذلك يحتاج API أو تكاملًا رسميًا متاحًا لحسابك.
- لا توجد إشعارات أسبوعية تعمل بالخلفية بعد إغلاق التطبيق.
- النسخ الاحتياطي واستعادة قاعدة بيانات التطبيق تحتاجان إلى استكمال قبل الاستخدام الإنتاجي.

## بناء APK
1. فك ضغط الحزمة على كمبيوتر.
2. افتح مجلد المشروع في Android Studio حديث.
3. اسمح بمزامنة Gradle وتنزيل الاعتماديات؛ الإنترنت مطلوب أول مرة.
4. اختر **Build > Build APK(s)**.
5. راجع Build Output واختبر APK على هاتف فعلي.
6. للتوزيع، اختر **Build > Generate Signed Bundle / APK** وأنشئ مفتاح توقيع آمنًا واحتفظ بنسخة منه.

## تنبيه
هذه نسخة تطويرية أولية. اختبرها ببيانات وهمية أولًا وخذ نسخًا احتياطية قبل إدخال سجلات مالية حقيقية. يلزم اختبار وتجميع فعلي في Android Studio قبل اعتبارها جاهزة للإنتاج.
